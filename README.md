# 🎵 Harmony Flow — Advanced Music Player

A fully interactive, feature-rich web-based music player built with **HTML**, **CSS**, and **JavaScript**. This modern music player provides a complete listening experience with playlist management, playback controls, audio visualizer, shuffle/repeat modes, speed control, and a beautiful responsive design.

[![Project Demo](https://img.shields.io/badge/demo-live-green)](https://music-player-one-gules.vercel.app/)
### Core Music Player
- **Play / Pause** — Toggle music playback
- **Next / Previous** — Navigate through the playlist
- **Progress Bar** — Click anywhere to seek within the current track
- **Volume Control** — Adjust volume with a slider

### Advanced Features
- **🔁 Repeat Modes**
  - Off — No repeat
  - One — Repeat the current track
  - All — Loop the entire playlist

- **🔀 Shuffle Mode**
  - Randomizes the playlist order
  - Preserves current track position

- **⏩ Playback Speed Control**
  - Toggle between: 0.75x, 1.0x, 1.25x, 1.5x

- **📊 Audio Visualizer**
  - Animated frequency bars that react to playback
  - Real-time animation while music plays

- **📋 Playlist Management**
  - Click any track in the list to play immediately
  - Active track is highlighted
  - Visual indicator shows currently playing song

- **💬 Toast Notifications**
  - User feedback for all actions (shuffle, repeat, speed, etc.)

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| **HTML5** | Structure of the player and playlist |
| **CSS3** | Styling, gradients, glassmorphism effects, responsive layout |
| **JavaScript (ES6)** | Audio control, playlist logic, event handling, state management |
| **Font Awesome 6** | Icons for controls and UI elements |
| **HTML5 Audio API** | Playback, time tracking, volume, speed |
